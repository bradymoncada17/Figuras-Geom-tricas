# Figuras Geométricas (StickerBoard)

## Descripción
Aplicación Windows Forms para crear y visualizar figuras geométricas (Rectángulo, Círculo, Línea, Triángulo) aplicando POO y Factory.

## Tecnología
- C# .NET Framework (o .NET 6 si usas WinForms .NET)
- Visual Studio

## Controles
- ComboBox: cmbFigura
- NumericUpDown: nudX, nudY, nudX2, nudY2, nudTamaño
- PictureBox: pbLienzo
- PictureBox: pbColor (vista color)
- ColorDialog: colorDialog1
- Button: btnCrear, btnLimpiar
- TextBox: txtContador

## Ejecución
1. Abrir en Visual Studio el ejecutable, recuerda extraer todo antes de abrir para que no haya problemas con la ruta de la carpeta.
2. Ejecutar.
3. Seleccionar color, parámetros y figura.
4. Presionar "Crear".
5. Para limpiar, presionar "Limpiar".
